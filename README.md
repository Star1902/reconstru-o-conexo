# Conexo — recriação front-end

Esta pasta contém uma recriação front-end inspirada na captura de tela enviada:
- `index.html`: estrutura da página
- `style.css`: aparência responsiva
- `script.js`: interações demonstrativas

## Como abrir
1. Extraia o ZIP.
2. Abra a pasta no Visual Studio Code.
3. Abra `index.html` no navegador ou use a extensão Live Server.

## Observações
Esta é uma implementação independente baseada somente na imagem de referência, não o código-fonte original do site. Login, pagamentos, arquivo histórico e envio de feedback são simulações locais e não se conectam aos serviços do site original. A fonte Inter é carregada do Google Fonts; sem internet, será usada uma fonte de sistema.
